# DESIGN.md — サバキャン WEBサイト デザイン仕様

`sabakyan-mock.html` のビジュアルデザインをまとめたスタイルガイドです。今後セクションを追加・編集する際は、このトーン&マナーに合わせてください。

## コンセプト

「サバゲー(昼・フィールド)× キャンプ(夜・焚き火)」の対比を色とレイアウトで表現。
地形図(等高線)・獣道の点線・掲示板といったアウトドア/ミリタリー由来のモチーフを、キャンプ用品ブランドのような落ち着いたトーンでまとめる。派手なグラデーションやSaaS的なカード意匠は避ける。

## カラーパレット

CSS変数として `:root` に定義済み。新しい要素を作る際もこの変数を使う。

| 変数名 | HEX | 用途 |
|---|---|---|
| `--canvas` | `#EDE6D2` | ページ全体の背景(キャンバス生地色) |
| `--canvas-deep` | `#E2D9BE` | お知らせ掲示板の下地など、やや濃い背景 |
| `--paper` | `#F6F1E4` | カード・テーブル等の紙面色 |
| `--forest` | `#232B1E` | 見出し文字色、夜パートの背景 |
| `--forest-deep` | `#161C12` | フッター背景、最終CTA背景 |
| `--olive` | `#4F5D3A` | 昼パート(サバゲー)のアクセント |
| `--olive-deep` | `#39432A` | 昼パートの濃色・タブ選択色 |
| `--ember` | `#C1481E` | メインアクセント(焚き火・CTA・重要タグ) |
| `--ember-deep` | `#9B3714` | ボタンホバー、重要タグの濃色 |
| `--khaki-line` | `#B5A97B` | 区切り線・点線・枠線(地形図の等高線イメージ) |
| `--ink` | `#221F17` | 本文の基本文字色 |
| `--ink-soft` | `#5C5645` | 補足文・キャプションなど弱めの文字色 |

**使い分けの原則**
- 昼(サバゲー)関連の強調 → オリーブ系(`--olive` / `--olive-deep`)
- 夜(キャンプ・焚き火)関連の強調、CTA、重要な告知 → エンバー系(`--ember` / `--ember-deep`)
- 背景の切り替え(セクション単位で明→暗にするのは「夜」を表すときのみ:ヒーロー右半分、コンセプトの夜カード、最終CTA、フッター)

## タイポグラフィ

Google Fonts を `<head>` で読み込み済み。

| フォント | ウェイト | 用途 |
|---|---|---|
| Zen Kaku Gothic New | 700 / 900 | 見出し(h1〜h4)、ロゴ、強調ラベル |
| Noto Sans JP | 400 / 500 / 600 / 700 | 本文全般 |
| Oswald | 400 / 500 / 600 | 数字・日付・時刻・セクション番号などの英数字アクセント(`.num` クラス) |

- 日本語の見出しには必ず `Zen Kaku Gothic New` の太いウェイト(700〜900)を使う。
- 日付・料金・時刻など数字が主役の要素には `.num` クラス(`Oswald`)を当て、英数字の質感を出す。
- 本文の行間は `line-height:1.75` を基本とする(読みやすさ優先)。

## レイアウトの基本ルール

- コンテンツ幅は `max-width:1080px` の `.wrap` で統一。
- 各セクションは `section.pad`(上下 `88px` の余白)を使用。
- セクション見出しは `.section-head` パターンで統一:
  `<span class="idx num">01</span><h2>見出し</h2>` — 2桁の連番(`01`〜)を `Oswald` の細字・エンバー色で添える。
  **連番はセクションを増減した際に必ず振り直すこと**(現在: 01 コンセプト / 02 開催概要 / 03 タイムスケジュール / 04 お知らせ / 05 持ち物リスト / 06 ルール・注意事項 / 07 アクセス / 08 よくある質問)。
- セクション間の区切りには `<div class="trail-divider"></div>`(点線)を使う。通常の `<hr>` や実線ボーダーは使わない。

## 主要コンポーネントのパターン

- **ヒーロー**:左45%を昼(オリーブ)、右55%を夜(深緑)に対角線グラデーションで分割。右側にエンバー色の光暈(焚き火の光)を配置。開催日・会場・料金などの要点は `.hero-meta` に3項目までのバッジ的表示。
- **コンセプト(昼/夜2分割)**:`.concept-grid` で左右2カードに分割し、左=紙面色(昼)、右=深緑背景(夜)のコントラストを付ける。
- **開催概要テーブル**:`.overview-table` は装飾を抑えたシンプルな定義テーブル。行間は点線ボーダーのみ。料金など補足(※)が多い項目はセル内に小さめの `--ink-soft` テキストでまとめる。
- **タイムスケジュール**:日ごとにタブ切り替え(`.day-tab` / `.day-panel`)し、各日は等高線風の点線を背骨にしたタイムライン(`.timeline`)で表示。マーカーはエンバー色の円。
- **お知らせ**:`.news-board`(掲示板の下地)の中に `.news-item` を積み重ねる。日付は左端に `Oswald` で表示し、タグは「お知らせ(オリーブ枠)」「重要(エンバー枠)」の2種類。新しい投稿ほど上に追加する運用。
- **持ち物リスト**:2カラム(サバゲー装備 / キャンプ装備)。必須アイテムには `<span class="req">必須</span>` バッジ(エンバー枠)を付与。
- **ルール・注意事項**:連番(`.rule-num`、薄いカーキ色の大きな数字)+見出し+説明文のリスト形式。
- **アクセス**:左に地図(現在は Google マップの `output=embed` 埋め込み、`.map-box` 内に `aspect-ratio:4/3` で収める)、右に `<dl>` 形式の詳細情報。
- **FAQ**:アコーディオン形式(`.faq-item` / `.faq-q` / `.faq-a`)。開いている項目は他を自動で閉じる仕様(JS制御)。
- **最終CTA・エントリー導線**:ヘッダー・ヒーロー・ページ下部CTAの3箇所にエントリーボタンを配置し、**同一の申し込みフォームURLに統一する**(URLを変更する際は3箇所すべてを更新)。ボタンは台形にカットした `clip-path` 形状(`.btn-primary` / `.btn-entry`)がこのサイト共通のCTA意匠。

## レスポンシブ

- ブレークポイントは `820px`。それ未満でナビを折りたたみ(ハンバーガーメニュー)、2カラム構成(コンセプト・持ち物・アクセス・お知らせ)は1カラムに変更する。
- 新しいセクションを追加する場合も、2カラム以上のグリッドは必ず `@media (max-width:820px)` で1カラムに変更するルールを踏襲する。

## 技術構成

- 単一HTMLファイル(CSS・JSをすべて埋め込み)。外部依存は Google Fonts の `<link>` と Google マップの `<iframe>` 埋め込みのみ。
- JSはフレームワーク不使用のバニラJS(タブ切り替え・アコーディオン・モバイルメニューの3機能のみ)。
- ローカルストレージ等の永続化は使用していない(静的なモックサイトのため)。
